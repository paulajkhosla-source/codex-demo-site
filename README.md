# Codex Demo

A single-page static site illustrating a simple Codex → Git → Vercel build pipeline.

## Files

- `index.html` — page content and structure
- `styles.css` — layout, styling and animation
- `script.js` — animation pause control
- `vercel.json` — Vercel configuration

## Preview locally

From this directory, run:

```sh
python3 -m http.server
```

Then visit `http://localhost:8000`. The site deploys to Vercel as a static site; no build step is required.
